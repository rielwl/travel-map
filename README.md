# travel-map

An interactive travel map, published with GitHub Pages and embedded in Notion.

## Live site

https://rielwl.github.io/travel-map/

## Structure

- `index.html` — the map page served by GitHub Pages

## Deploying

Pages builds from the `main` branch root. Push to `main` and the site updates
within a minute or two.

## Embedding in Notion

Paste the live-site URL into a Notion page and choose **Embed**.
